# Tarea 3.3: aporte sugerido con tope

- **Rama base:** `pivote/b2b-sin-pagos`. Crea `pivote/3.3-aporte-sugerido` y abre un PR contra la rama base.
- **Contexto:** lee `docs/REGLAS_DE_NEGOCIO_Y_TARIFAS.md`, secciones 1.2 y 1.3.
- **Servicios afectados:** `services/route-matching-service/` (principal) y `services/trip-service/` (un ajuste de validación).
- **Dónde vive la regla:** el aporte se fija **al publicar la ruta** (route-matching es dueño de la ruta, de su distancia y de `base_contribution_cop`). Por eso la fórmula y el tope viven **solo en route-matching-service**. Esto reemplaza lo que decía el plan sobre "endpoint en trip-service".
- **Sin renombres:** se mantienen `routes.base_contribution_cop` (el aporte indicado por el conductor) y `trips.total_fare_cop` (el aporte acordado en la reserva), para no romper la app ni el paquete compartido. El cambio de nombre queda descartado.

## Regla (fuente: reglas, §1.2)
```
aporte_sugerido = redondear_arriba_a_100( APORTE_BASE + distancia_km × APORTE_KM )
```

| Tipo de vehículo | `APORTE_BASE` | `APORTE_KM` |
|---|---|---|
| `carro` | 2000 | 400 |
| `moto` | 1000 | 250 |

- El conductor indica `base_contribution_cop` con **`0 ≤ valor ≤ aporte_sugerido`**.
- `distancia_km` = la distancia vial de la ruta (`distance_meters / 1000` que devuelve `OsrmRoutingService::calculateRoute`, incluido su *fallback* geodésico).

## route-matching-service

### 1. Configuración
`config/uniwheels.php` (nuevo, o un bloque en un config existente si ya hay uno de negocio) con:
```php
'contribution' => [
    'carro' => ['base' => (int) env('CONTRIBUTION_CAR_BASE', 2000), 'per_km' => (int) env('CONTRIBUTION_CAR_PER_KM', 400)],
    'moto'  => ['base' => (int) env('CONTRIBUTION_MOTO_BASE', 1000), 'per_km' => (int) env('CONTRIBUTION_MOTO_PER_KM', 250)],
],
```
Agrega las 4 variables a `.env.example`.

### 2. `app/Services/ContributionCalculator.php` (nuevo)
- `suggest(float $distanceKm, string $vehicleType): int`
  - Aplica la fórmula y redondea hacia arriba a la centena (`(int) (ceil($valor / 100) * 100)`).
  - `$vehicleType` desconocido lanza `InvalidArgumentException`.
  - `$distanceKm < 0` se trata como 0.

### 3. Tipo de vehículo confiable
En `DriverProfileClient`, agrega `getVehicleType(string $vehicleId): ?string`:
- Llama al mismo endpoint `/vehicles/{id}/public-summary`.
- Retorna `'carro'` o `'moto'`, o **`null` si falla** (sin *fallback* a `carro`: el tope no se puede calcular a ciegas).
- No cambies `getVehicleSummary`.

### 4. Endpoint de sugerencia
`GET /api/v1/routes/contribution-suggestion`, con `jwt.auth` igual que la publicación.
- **Entrada**, con FormRequest `ContributionSuggestionRequest`: `vehicle_id` (uuid), `origin_lat`, `origin_lng`, `destination_lat`, `destination_lng`, con los mismos rangos de `PublishRouteRequest`.
- **Proceso:** `calculateRoute(origen, destino)` → km, y `getVehicleType` → tipo.
- **Respuesta 200:**
  ```json
  { "success": true, "data": { "distance_km": 8.4, "vehicle_type": "carro", "suggested_contribution_cop": 5400, "max_contribution_cop": 5400 } }
  ```
  `distance_km` redondeado a 1 decimal.
- Si `getVehicleType` devuelve `null`, responde **503** con `"No fue posible validar el vehículo. Intenta nuevamente."`.
- Declara la ruta **antes** de cualquier `/routes/{id}`, para que no la capture.

### 5. Publicación de ruta (`PublishRouteRequest` + `RouteController::store`)
- En `PublishRouteRequest`, `base_contribution_cop` pasa a `['required', 'integer', 'min:0']`. Quita el `max:25000` y el mensaje del mínimo de $2.000.
- En `store`, después de `calculateRoute`:
  1. Toma la distancia de `$calculoRuta['distance_meters']`.
  2. Obtén `getVehicleType($datos['vehicle_id'])`. Si es `null`, responde **503**, igual que en el punto 4.
  3. Calcula `$sugerido = ContributionCalculator::suggest(...)`.
  4. Si `base_contribution_cop > $sugerido`, responde **422** con `errors.base_contribution_cop = ["El aporte máximo para esta ruta es de $ X COP."]` (con X formateado como el resto del archivo) y con `data.max_contribution_cop`.
  5. Guarda en la ruta `distance_km` y `suggested_contribution_cop` (ver la migración).
- Incluye `distance_km` y `suggested_contribution_cop` en las respuestas de ruta donde hoy aparece `base_contribution_cop`.
